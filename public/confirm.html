Downloading runs a script on your OWN computer. It opens a real, separate Chrome window on Google's real sign-in page — you type your password directly into that page, never into this website.

After downloading:
  1. Open a terminal in the folder where it downloaded
  2. Run once: npm install playwright then npx playwright install chromium
  3. Run: node forward-agent.js
  4. A real Chrome window opens with your email filled in — type your own password into it
  5. The rest happens automatically
